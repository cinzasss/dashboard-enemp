# Dashboard ENEMP

Dashboard interativo para análise de participantes e trabalhos submetidos ao ENEMP.

## Funcionalidades

- Análise de participantes (inscritos, aprovados, formação acadêmica)
- Instituições dos participantes (por estado e região)
- Análise de trabalhos submetidos (pôster, oral, student contest)
- Autores com múltiplos trabalhos
- Exportação de dados em CSV

## Como usar

1. Acesse o link do dashboard
2. Faça upload das planilhas `.xlsx` na barra lateral
3. Explore os indicadores e gráficos
